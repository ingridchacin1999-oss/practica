# Proyecto de Seguridad Informática: SQLi, Escaneo de Red y Hardening - UNEMI 2026

Este proyecto es una práctica académica desarrollada para la asignatura de **Seguridad Informática** de la Universidad Estatal de Milagro (UNEMI).

## Módulos incluidos
1. `app_vulnerable.py`: Aplicación Flask simulada con rutas vulnerables y corregidas contra SQL Injection.
2. `ataque_sql_i.py`: Script de prueba automatizado para validar el bypass de autenticación.
3. `escaneo_red.py`: Módulo de escaneo básico de puertos de red y buenas prácticas de hardening en bases de datos relacionales.

## Requisitos de Ejecución
- Python 3.x
- Flask (`pip install flask`)
- Requests (`pip install requests`)
